A memory release: one slow leak and three ways of running out, all four in every release so far.

- Every update check, twice a day by itself, kept 360 bytes of internal RAM and 12 KB of PSRAM for good; a device left running for months would have run out.
- On a network of several access points (a mesh) the device joins the strongest one, not the first it hears; on a far one uploads stalled.
- Several large files handled at once could ask for more memory than there is and restart the device; the file that does not fit is refused with its reason.
- Pages loaded again and again while the device talked to a server could take nearly all its internal RAM; what they can take is now bounded.
