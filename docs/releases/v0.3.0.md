Cardless operation, a hardened web interface and a new clock face.

- A p64 without a microSD card is a supported mode: downloaded artwork is kept in memory, up to 8 playsets live on the device, and the pages hide what needs a card.
- A card that stops answering no longer stalls the device, and a card without a file system can be formatted from Settings > Storage.
- The web interface resists slow, repeated and foreign requests: timeouts, a busy answer instead of a queue, requests from other sites refused, bursts of settings written to flash once.
- New clock face: the beach, with the tide following the moon.
- An IMU that misses its probe at boot is found later, so taps and auto-rotation come back without a restart.
- Settings: the Time section moved to Widgets, above Weather; the Makapix refresh interval is spelled out in words.
- New defaults, for a device without stored settings: rotation 270, raw p64 UDP streams off (DDP stays on).

Update from v0.2.2 on the device's Update page. Flash from the browser at https://fabkury.github.io/p64/web-flasher/ or with esptool: https://github.com/fabkury/p64/blob/main/docs/flash-firmware.md
