The first published firmware of p64, a desktop 64x64 LED matrix built from Waveshare's ESP32-S3-RGB-Matrix board and P2 64x64 panel in a printed shell.

- Plays GIF, WebP, PNG, APNG and BMP artwork from a microSD card and from Makapix Club, never skipping a frame.
- Clock faces, weather, air quality and the board's temperature sensor as widgets; a night schedule.
- Live pixels over DDP or raw UDP; browser controls with live preview, playsets, an optional PIN and a documented HTTP API.
- Tap gestures and auto-rotation from the IMU; the two knobs of p64b.
- Updates over Wi-Fi from this page onward, with checksum verification and rollback.

Flash it from the browser at https://fabkury.github.io/p64/web-flasher/ or with one esptool command: https://github.com/fabkury/p64/blob/main/docs/flash-firmware.md. Build guide: https://github.com/fabkury/p64/blob/main/docs/build-your-own.md
