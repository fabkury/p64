Other device photos in this folder predate that migration and are deprecated for
current documentation. In particular, `p64-brick-wall-analogue-clock.jpg`,
`p64-brick-wall-weather.jpg` and `p64-brick-wall-jellyfish.jpg` show v1.
Retain older photos as historical source material; label their version explicitly
if used in an archive. Do not present them as the current enclosure or relabel their
subjects to substitute for missing v7a photographs.
