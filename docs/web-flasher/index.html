p64 web flasher

Puts the firmware on the controller over USB. No tools to install.

This browser cannot flash

Flashing uses the Web Serial API. Use one of:

  • Google Chrome 89 or newer
  • Microsoft Edge 89 or newer

Firefox and Safari do not offer it. The command-line guide works everywhere.

1. Choose the firmware

2. Connect the controller

Plug a USB-C data cable into the controller's USB port (on an assembled p64: the right-hand port from behind, the one with the groove). The POWER port carries no data. The panel may stay powered from its supply.

In the browser's dialog pick the USB JTAG/serial debug unit (Windows may show it as USB Serial Device or a COM number).

Not connected

3. Flash

Done

The controller restarts with the new firmware. On a device that has never been set up (or after an erase) a Wi-Fi network named p64-setup appears within about a minute: join it to choose your network. A device that was already set up simply comes back on its network at p64.local.

Later updates install over Wi-Fi from the web UI's Update page; this flasher is only needed the first time or to recover a device.
