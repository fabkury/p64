## INITIAL DEFINING FEATURES OF P64:
 - Accurate, tearless, jitterless playback of animations up to 128x128 px, 60 fps. Sizes bigger than 64x64 (native panel size) are downscaled by averaging pixels, while sizes smaller than 64x64 are upscaled using crisp nearest-neighbor interpolation. Aspect ratios are always respected and preserved when scaling (letterbox/pillarbox are used as needed, using the background color).

 - Full support for animated GIF, APNG, WEBP, including transparency and alpha channel as per each format.

 - Full support for static GIF, WebP, PNG and BMP, including transparency and alpha channel as per each format.

 - Configurable background color (default black, RGB 0,0,0).

 - Configurable brightness (default maximum).

 - Two modes of operation: quality mode (lower Hz, higher color richness), photo mode (much higher Hz, less banding in photos).

 - Seamless transition between main states of operation. Initial main states of operation:
  a. Animation show: auto-swap (change) animation every X seconds, X defaults to 30, configurable from 5 to 86400 (if configured to 0 there's no auto-swap, i.e. infinite seconds). Optional clock on the top left (default) or any of the corners. Last 32 animations played are kept in playback history, so the user can easily go back. Swap from one animation to another is instantaneous with no jitter or stutter. User can swap back and forth along the animation show history by using the web UI (more about the web UI below).
  b. Widget: each widget renders the screen its own way. Initial widgets: 1) full screen clock with configurable font (see fonts in folder assets/fonts/), 2) weather forecast with pixel art icons and symbols (icons and symbols need to be drawn to raster files ahead of time).
  c. Stream: device receives pixels directly from a network command and/or stream. Prioritizes low latency, responsiveness, and compatibility.

 - Device connects to user's wifi if it has working SSID and password. If it doesn't, or if the SSID/password doesn't work, device falls back to soft AP for network setup.

 - While in soft AP mode, LED matrix displays helpful information for Wi-Fi setup including device LAN IP. User can connect to soft AP and access a streamlined web interface for configuring WiFi SSID and password.

 - When not in soft AP mode, i.e. when connected to user's wifi, a web interface is also offered to control the device. This web interface replicates as closely as possible the feature set and layout of p3a's web interface: https://GitHub.com/fabkury/p3a. This includes:
  a. Full support for up to 32 playsets.
  b. Each playset supports up to 64 channels.
  c. Each channel supports up to 8192 artworks.
  d. Different kinds of channels: local microSD card, Makapix Club channels.

 - Full support for downloading and playing an artwork from an arbitrary URL, similar to how p3a does.
