We really shouldn't trust RTC, because as you correctly pointed out, the RTC has no battery connected to it. What I mean is, we can only trust NTP. Being NTP-sync'ed must be a fundamental requirement for accepting the validity of timestamps. The device must always sync to NTP on boot and periodically thereafter. Some edge cases, such as the user uploading a file in the web UI before the sync to NTP (which is extremely unlikely in practice) are accepted as deviations. Please implement those principles in the code in a production-grade way.
