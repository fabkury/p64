The text of that "build your own" page, as well as other pages sometimes, is giving more information than necessary. For example, the sentence "it has only ever been printed that way" is unnecessary. This kind of "development notes" doesn't need to be present in the user-facing documentation. The user-facing documentation should focus on instructing the user as briefly and concisely as possible, without wasting time in "teaching the user how the development process looked like along the way." For every piece of information, consider: is it actually useful for the user? Even if it is useful, should it be front and center or relegated to an appendix?
